# **App Name**: CineMatic

## Core Features:

- User Authentication: Secure user login/signup with username/password and JWT for protected routes.
- Movie Recommendations: Provide movie recommendations based on hybrid model (NCF and content-based).
- Trailer Integration: Embed YouTube trailers within the app using the YouTube Data API and embed IDs.
- Download Tracking: If available, enable movie downloads and track user download history.
- Search and Filter: Enable users to search for movies and filter by genre and language.
- NCF Model Trainer Tool: Train the Neural Collaborative Filtering model to create personalized recommendations for the users; the tool reasons whether ratings data for individual movies exceeds the threshold that would make it beneficial to use it as part of the output
- Movie DB Build Tool: A script to build and augment the movies database with additional useful information

## Style Guidelines:

- Primary color: Deep Indigo (#4B0082) to convey a sense of sophistication and cinematic experience.
- Background color: Very dark gray (#1A1A1A) to create an immersive viewing environment.
- Accent color: Gold (#FFD700) for highlights and call-to-action buttons to add a touch of luxury.
- Body text: 'Inter' sans-serif for clear and modern readability. Headline font: 'Space Grotesk' for a techy feel.
- Code snippets: 'Source Code Pro' for clear code snippets display
- Use clean, minimalist icons for navigation and actions.
- Responsive design with clear grid system for movie listings and details.
- Subtle transitions and loading animations to enhance user experience.
